# 教师手册历史示例材料

本目录保存编写教师手册时仓库已有结果的独立副本，便于教学引用。它不是此次编写过程中重新训练或重新推理得到的验证记录；原结果没有完整配置、软件版本和硬件元数据，不承诺重新运行得到完全相同的数值。

后续运行两个入口会覆盖 `outputs/` 中的同名文件，本目录中的副本不随之更新。学生必须提交自己运行的结果，不能把本目录的指标和图片作为个人实验成果。

检测插图源自项目已有的 COCO8 示例。原始图片来源与许可线索见 `detection_sources.csv`；图片各自遵循原作者许可，不能把 COCO 数据集的使用说明当作对所有图片的统一授权。复用材料时保留来源记录，按实际使用场景核查图片许可。

手册中的分类表格由历史 CSV 四舍五入显示，验证 Accuracy 最大值在第 4 轮；测试记录为 Accuracy 0.7660。检测表来自历史 CSV，包含 8 张图片、每张 3 个阈值、共 24 行。同图的耗时为共享值，不是三次独立测量。
