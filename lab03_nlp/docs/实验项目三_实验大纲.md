# 《深度学习与应用》实验大纲

## 实验项目三：基于循环神经网络的中文文本情感分类与模型比较

适用于人工智能专业本科三年级

### 一、实验基本信息

| 项目 | 内容 |
|---|---|
| 所属课程 | 深度学习与应用 |
| 实验对象 | 人工智能专业本科三年级学生 |
| 实验学时 | 共 8 学时，第 5 次课与第 6 次课各 4 学时 |
| 实验性质 | 综合性实验，含程序阅读、实现、验证和分析 |
| 实验形式 | 教师讲解与演示，学生上机实践，完成一份综合实验报告 |
| 实验环境 | 普通笔记本 CPU；Python、PyTorch、NumPy、Matplotlib |
| 先修基础 | CNN、反向传播、优化器、PyTorch 基本训练流程及 RNN、LSTM 基本原理 |

### 二、实验目标

1. 解释字符 ID、Embedding、循环层隐藏状态和分类分数的作用，正确说明主要张量维度的变化。
2. 完成真实中文情感数据的读取、有效性检查、去重、抽样、字符编码、截断、右侧填充及批量加载。
3. 搭建小型单向单层 LSTM 和普通 RNN 分类模型，按有效长度提取最后有效状态，验证前向传播、反向传播、梯度裁剪和参数更新。
4. 完成训练、验证、最佳模型保存与加载，区分训练集、验证集和测试集的用途，避免数据泄漏和测试集调参。
5. 在一致条件下比较 Accuracy、参数量、累计训练时间和训练曲线；结合至多三条真实误分类给出有依据的分析。
6. 形成可复现的实验记录和综合报告，如实表述实验结果，明确数据转换、文本截断和单次实验结论的边界。

### 三、教学重点与难点

**教学重点：** 字符编码与 Embedding；RNN/LSTM 的结构与张量维度；完整训练及评价流程；模型比较和真实错误分析。

**教学难点：** 只根据训练集建立字符表；最后有效状态如何避开 PAD，以及它与平均池化的信息传递方式差异；按验证表现选模型；解释相同隐藏维度下参数量不同，以及 LSTM 不一定更准确的原因。

### 四、实验内容与学时分配

以下按每次课 4 个教学单元安排，共 8 学时；每学时的实际分钟数按学校课表执行。

#### （一）第 5 次课：文本处理与 LSTM 情感分类（4 学时）

| 学时 | 实验任务 | 完成标志与观察内容 |
|---|---|---|
| 1 | 检查 Python 与依赖；读取公开数据；检查空文本、无效标签及重复文本；保留官方划分并固定抽样。 | 给出数据来源、标签转换规则及各集合正负数量；确认三个集合没有重复全文。 |

| 1 | 阅读并实现 Embedding—LSTM—最后有效状态—分类层；了解 Dropout 和梯度裁剪；完成单批次检查。 | 打印模型结构、张量形状和参数量；确认前向、反向及 Adam 更新正常。 |

本次课阶段成果：处理后的数据与字符表、真实编码示例、LSTM 最佳验证模型、训练记录及曲线。此阶段不以测试集成绩决定训练设置。

#### （二）第 6 次课：RNN 与 LSTM 比较（4 学时）

| 学时 | 实验任务 | 完成标志与观察内容 |
|---|---|---|
| 1 | 将循环层切换为普通 RNN；复用数据、训练和验证函数；按相同超参数完成训练。 | 保存 RNN 最佳验证模型及日志；核对两模型的数据和训练条件一致。 |
| 1 | 分别加载按验证 Accuracy 选出的最佳模型；在同一测试集上进行最终评价。 | 输出两模型测试 Accuracy 与正确数/总数；保存全部测试预测。 |
| 1 | 汇总 Accuracy、参数量、累计训练时间、最佳轮次和训练曲线，生成比较表及图片。 | 核对时间统计范围；解释性能和计算成本差异，限定结论适用条件。 |
| 1 | 查看最多三条真实误分类，对照全文与模型可见前缀；整理综合报告。 | 展示真假标签及文本依据；分析否定、转折、截断、标签歧义或训练不足等可能因素。 |

本次课阶段成果：RNN 最佳模型、两个模型的最终测试记录、比较表与图片、误分类分析和两次课综合报告。

### 五、实验方案与技术要求

#### （一）数据与文本编码

采用作者公开的 ASAP 中文餐饮评论数据集，发布仓库附 Apache-2.0 许可。原始数据共 46,730 条，带整体星级评分及官方训练、验证、测试划分。项目可自动下载固定版本并校验文件，也支持按数据说明手动下载后离线处理。

1. 使用整体星级构造二分类：1–2 星为负面（0），4–5 星为正面（1），排除 3 星；不使用细粒度方面标签。
2. 检查无效记录，移除标签冲突全文，对其余全文全局去重；保持官方集合归属，在各集合内按固定种子无放回均衡抽样。
3. 默认抽取 2500 条，训练/验证/测试分别为 2000/250/250，各集合正负各半。均衡抽样后的类别比例与原始平台不同。
4. 只用训练集建立字符表，PAD=0、UNK=1。保留否定词和常见标点，不分词；最大长度 256，超长截断，不足右填充，保存有效长度。

**数据局限：** 默认抽样中有 1473 条超过 256 字，模型最多看到前 256 字；整体星级也可能与局部文本情绪不同。报告必须说明这两点，不能把前缀分类描述为完整评论的理解能力。优化版与旧版保留同一批样本及标签，验证集用于选择输入长度和最佳轮次。

#### （二）网络结构与统一配置

统一结构：字符 ID → Embedding → Dropout → RNN 或 LSTM → 最后有效状态 → Dropout → 全连接层 → 两类 logits。早期信息需要通过循环状态传递到有效前缀末端；保留平均池化用于对照。此设置适合讨论序列信息传递，不保证更高的绝对准确率，也不单独证明长距离依赖的因果作用。

| 参数 | 默认设置 | 参数 | 默认设置 |
|---|---|---|---|
| 最大序列长度 | 256 | Embedding 维度 | 64 |
| 隐藏维度 | 64 | 网络层数 | 1 |
| 网络方向 | 单向 | Batch Size | 32 |
| Epoch | 20 | 优化器 | Adam |
| 学习率 | 0.002 | 损失函数 | CrossEntropyLoss |
| 表示方式 | 最后有效状态 | Dropout | 0.2 |
| 权重衰减 | 0.0001 | 梯度范数上限 | 1.0 |
| 随机种子 | 42 | 计算设备 | CPU |
| CPU 线程数 | 2 | 最佳模型依据 | 验证 Accuracy |

张量变化：[N,L] → [N,L,E] → [N,L,H] → [N,H] → [N,2]。N 为批次样本数，L 为序列长度，E 为嵌入维度，H 为隐藏维度。对每条文本取索引 `length-1` 的循环输出；不能取填充后的最后一步。平均池化对照模式用有效长度掩码排除 PAD。分类层不添加 softmax，交叉熵直接接收 logits。

#### （三）训练、评价与比较规范

仅训练集进行梯度更新，验证集用于选择配置与最佳轮次，测试集在两模型训练结束后做最终评价。同验证 Accuracy 时保留较早轮次。默认 20 Epoch；需要其他轮数时，应在最终测试前确定，且两模型一致。

两模型使用相同数据、字符表、维度、批次顺序、初始 Embedding、池化方式、Dropout、权重衰减、梯度裁剪及其他超参数和线程数。训练时间仅累计各 Epoch 的训练批次，含加载、前向、反向、梯度裁剪和参数更新，排除下载、单批次检查、验证、保存、绘图与测试。相同隐藏维度不等于相同参数量；不预设 LSTM 必须更准确或更快。

### 六、组织实施与操作流程

#### （一）课前与课堂组织

教师课前核验数据来源、运行环境和默认端到端流程，准备无法联网时的手动数据获取说明。学生复习 RNN/LSTM、交叉熵与 PyTorch 训练步骤。课堂按“原理说明—代码阅读与实现—运行核对—结果讨论”开展。

基础实验使用普通 CPU，不要求 NVIDIA 显卡；使用 Python 3.10 及以上版本，依赖 PyTorch、NumPy、Matplotlib。环境安装按项目 README 执行，优先沿用已有可用环境。学生需理解、补充或修改指定核心代码，并能解释运行过程，不能只提交终端输出。

#### （二）点击运行流程

在 VS Code 中选择已安装依赖的解释器（当前工作区为 /opt/conda/bin/python），依次打开下表中的文件并点击右上角“运行 Python 文件”三角按钮。无需输入命令；每一步结束后再运行下一步。

| 阶段 | 点击运行的文件 | 主要输出 |
|---|---|---|
| 数据准备 | prepare_data.py | 数据统计、字符表、编码示例和处理后的样本。 |
| LSTM 检查与训练 | check_lstm.py → train.py | 结构与更新检查、最佳模型、日志和曲线。 |
| RNN 检查与训练 | check_rnn.py → train_rnn.py | 相同条件下的 RNN 最佳模型、日志和曲线。 |
| 最终测试 | evaluate.py | 两模型最终测试指标、全部预测及真实误分类。 |
| 结果比较 | compare.py | 指标比较表、柱状图及训练曲线对比图。 |

每次正式训练也会自动执行单批次检查。需要离线处理时，将 prepare_data.py 顶部的 OFFLINE 改为 True 后点击运行。教师或学生排错可直接点击运行 test_pipeline.py；功能检查中的临时文本不作为实验数据。训练参数统一在 train.py 顶部设置，最大长度在 prepare_data.py 顶部设置。

两次课合并提交一份综合实验报告，并附能够追溯报告结果的源代码、日志、表格及图片。报告使用项目中的“实验报告模板.md”，至少包含：

2. 数据来源与许可、标签转换、类别统计、划分与去重说明，以及一条真实字符编码示例。
3. LSTM/RNN 结构、张量维度、单批次检查、训练曲线和最佳验证轮次。
4. 同一测试集上的 Accuracy、参数量、累计训练时间比较表，并明确计时范围。
5. 最多三条真实误分类的原始文本、可见前缀、真假标签及有依据的可能原因；不足三条时按实际数量提交。
6. 基于实际结果的结论、实验局限、遇到的问题与解决过程。

结果位置：data/processed/ 保存数据与字符表；outputs/lstm/ 与 outputs/rnn/ 保存模型和日志；outputs/comparison/ 保存比较表和图片；outputs/misclassified.csv 保存错误样本。具体文件职责和操作说明见 README 与实验指导书。

### 八、考核评价建议

建议采用以下百分制方案，依据可复现的基础成果、现场解释和综合报告评价，不以达到某个固定 Accuracy 作为评分前提。

| 考核内容 | 分值 | 主要评价依据 |
|---|---|---|
| 数据处理与字符编码 | 20 | 来源清楚；检查、去重和抽样正确；字符表仅来自训练集；编码、填充及有效长度说明正确。 |
| LSTM 建模与训练 | 25 | 结构与维度正确；提取最后有效状态时避开 PAD；单批次更新正常；训练/验证、最佳模型保存和日志完整。 |
| RNN 实现与训练 | 15 | 正确替换循环层并复用流程；数据和超参数保持一致；模型、最佳轮次和训练记录可追溯。 |
| 最终测试与模型比较 | 20 | 加载最佳验证模型；在相同测试集评价；Accuracy、参数量和时间统计真实、比较规范。 |
| 错误分析与综合报告 | 20 | 错误来自真实预测；分析对照实际输入；图表完整；能说明截断、标签及单次结论的局限。 |
| 合计 | 100 | 完成基础任务、结果真实、分析准确即可获得满分。 |

不设置新增 GRU、Transformer、注意力、预训练模型或多随机种子实验等额外满分条件。训练指标较低本身不扣分，应结合实现正确性和分析质量评价。不得编造指标、图片或训练完成状态；具体成绩处理遵循课程既有要求。

### 九、思考与讨论问题

1. 为什么字符 ID 不能直接表示语义大小？Embedding 的向量在什么阶段更新？
2. 为什么只能根据训练集建立字符表？PAD 与 UNK 的用途有何不同？
3. PAD 嵌入为零时，为什么平均池化仍需要有效长度掩码？与最后有效步模式有何区别？
4. 训练集、验证集和测试集各有什么作用？为什么最佳验证模型可能不是最后一轮模型？
5. 相同 Embedding 和隐藏维度下，RNN 与 LSTM 为什么参数量不同？为什么 LSTM 不一定更准确？
6. 256 字截断、整体星级标签与均衡抽样如何影响评价？多项设置同时变化时，能否把准确率提升全部归因于某一项？这次实验能否证明某模型普遍优于另一模型或长期依赖能力必然更强？
