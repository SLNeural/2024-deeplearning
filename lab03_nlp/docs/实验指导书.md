## 第 5 次课：文本处理与 LSTM 情感分类

### 一、实验目的

1. 理解文本如何转换成整数、向量和批次张量。
2. 理解 Embedding、LSTM 与全连接分类层的作用和输入输出维度。
3. 完成一次前向传播、损失计算、反向传播和参数更新。
4. 使用训练集学习参数，使用验证集选择最佳轮次，保存模型及训练记录。

### 二、必要原理

**字符 ID 与 Embedding。** 文本不能直接输入循环网络。先为每个训练集字符分配整数 ID。整数仅代表查表位置，不代表语义大小或距离；“好”的 ID 大于“坏”并不意味着更正面。Embedding 为每个 ID 查出一行可训练向量，使字符表示能随分类任务更新。它从随机初始化开始学习，不是预训练语言模型。PAD 表示补齐位置，UNK 表示训练字符表没见过的字符。

**时间步与循环网络。** 字符顺序是时间顺序，每一步接收当前字符向量并更新隐藏状态。LSTM 在隐藏状态之外还有细胞状态，通过输入、遗忘、输出门控制信息更新。普通 RNN 没有这些门，结构和参数更少。本实验只需调用 PyTorch 模块，不需要手写门公式。

**有效长度与最后有效状态。** 短文本右侧用 PAD 补到 256。循环网络即使读到零向量也可能因递归状态和偏置继续改变隐藏值，所以不能直接取填充后的最后一步。默认 `pooling="last"` 对每条样本取 `length-1` 处的隐藏表示，得到 `[N,H]`。前面出现的线索需要通过循环状态传递到这个位置，适合观察两种循环结构的信息传递效果。因为本实验为单向网络，右侧后续填充不会改变有效前缀的输出；这里不需要 PackedSequence。

另一种表示方式 `pooling="mean"` 用 `positions < lengths` 掩码排除 PAD，再对所有有效位置的输出取平均，可以直接汇总各位置线索。上一版平均池化结果保存在 `outputs/baseline_256_mean/`。最后有效状态与平均池化各有取舍，前者不保证更高的绝对准确率。若要单独研究池化方式的影响，应保持训练轮数和其他设置一致，分别训练两个模型，不把不同版本的多项变化归因于单一因素。

**训练稳定性。** 默认在 Embedding 后和分类前使用 Dropout=0.2，在训练中随机置零部分特征，评价时自动关闭。Adam 使用权重衰减 0.0001；反向传播后将梯度总范数限制为 1，再更新参数。这些设置用于改善泛化和训练稳定性，不能保证所有数据上都提高准确率。

| 张量 | 维度 | 含义 |
|---|---|---|
| 字符 ID | `[N,L]` | N 条文本，每条 L=256 个字符位置 |
| Embedding 输出 | `[N,L,E]` | 每个 ID 对应 E=64 维向量 |
| 循环层输出 | `[N,L,H]` | 每个位置产生 H=64 维隐藏表示 |
| 最后有效隐藏状态 | `[N,H]` | 每条文本取 `length-1` 处输出，避开右侧 PAD |
| 分类 logits | `[N,2]` | 每条文本有负面/正面两个未归一化分数 |
| 标签、有效长度 | 各 `[N]` | 每条文本对应一个标签和长度 |

`CrossEntropyLoss` 直接接收 logits 和整数标签，不在模型最后加 softmax。预测用 `logits.argmax(dim=1)`。

**训练、验证和测试。** 训练集用于反向传播。验证集用于比较轮次/设置，不能反向传播。训练轮数增加不保证泛化更好，所以保存验证 Accuracy 最高的模型，而不一定保存最后一轮。测试集只在两个模型都训练完后做最终评价；看过测试结果后不能再围绕该测试指标反复调整参数。

## 第 6 次课：RNN 与 LSTM 比较

### 一、实验目的

在同一流程下替换循环层、训练 RNN，加载各自最佳验证模型，在同一测试集上比较 Accuracy、参数量、时间和训练曲线；结合真实错误分析局限。

### 二、步骤 1：切换模型并检查

沿用上节课的数据、字符表和环境，不重新抽样。打开 `models.py` 找到 `nn.LSTM if ... else nn.RNN`，观察两者共用的 Embedding、Dropout、最后有效状态索引与分类层。

打开 `check_rnn.py`，点击右上角运行。

记录 RNN 的结构与参数量。默认为 256,962，输出仍是 `[N,2]`。比较时输出维度、Embedding 和隐藏维度相同，但循环层内部结构不同。

参数为何不同？PyTorch 单层 RNN 有输入到隐藏矩阵、隐藏到隐藏矩阵和两组偏置，循环层参数为 `H×E + H×H + 2H`。LSTM 对四组门/候选状态计算对应矩阵和偏置，循环层约是上述的 4 倍；Embedding 和分类层相同。因此完整网络的参数总量不是简单的 4 倍。

### 三、步骤 2：使用相同条件训练 RNN

打开 `train_rnn.py`，点击右上角运行。该入口固定选择 RNN，超参数仍取自 `train.py` 顶部，不需要修改模型名称。

### 六、步骤 5：最多三条误分类分析

打开 `outputs/misclassified.csv`。程序共选最多三条不重复真实错误，按测试文件顺序优先选 LSTM，不足时从 RNN 补足；若总共不足三条就展示全部，不人为制造错误。其他错误可从完整预测 CSV 查看。

每条记录均包含模型、原文、模型可见前 256 字、有效长度、是否截断、真假标签及中文标签名。填写报告时引用原始文本，再指出模型实际看到了哪些内容。候选分析方向包括：

- 否定、转折或反讽，例如前面褒扬、后面批评；需结合实际文本，不可机械套用。
- 截断后丢掉结论：原文的信息不等于模型输入的信息。
- 评论中同时谈及多个方面，前缀情绪与整条评论星级不一致。
- 样本、训练轮次和字符表示学习不足，或未知字符增加理解困难。

把原因写成基于文本的可能解释，不把一个错误样本当作因果证明。如果仅凭文本无法确定原因，可以明确写“无法从当前记录确定”。

### 七、为什么 LSTM 不一定更准确？

门控有助于信息控制，但更多参数需要足够数据和合适训练；小样本、短输入、少量 Epoch、初始化、优化过程、标签噪声及截断都可能影响结果。普通 RNN 可能足以捕捉当前前缀中的线索。最后有效状态使早期信息需要通过循环状态传递，适合讨论记忆机制；真实评论仍未控制情感线索的位置和依赖距离，因此不能仅凭 Accuracy 差异证明长距离记忆的因果作用。

允许写“在当前教学子集与设置下，某模型的测试 Accuracy 更高”，不能写“本实验已经证明 LSTM 总优于 RNN”或“已经证明长期依赖能力必然更强”。若两个模型表现接近或 LSTM 较低，按真实结果报告，不回头反复调测试集成绩。
